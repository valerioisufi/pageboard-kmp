# The name and the icon of PencilNotes

The code of this repository, PencilNotes included, is under the [MIT License](../LICENSE): you may
use it, change it and publish what you build with it.

The name **PencilNotes**, its wordmark and its icon (`pencilnotes/shared/src/commonMain/composeResources`,
the launcher icons of `androidApp`, `desktopApp` and `iosApp`) are not part of that license. They
identify the application published by its author. An application built from this code and
published by someone else, in a store or anywhere else:

* has a name and an icon of its own, that cannot be mistaken for PencilNotes;
* has an application id and a bundle id of its own (not `com.studiomath.pencilnotes` or
  `io.github.valerioisufi.pencilnotes`).

Saying that it is based on PencilNotes or on DrawView is welcome. The libraries (`drawview-*`) have
no such restriction: their names are the names of the modules.
